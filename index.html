NILAVUS

A personal cloud and distributed home server built from repurposed hardware, with one dashboard to reach every service locally or remotely.

  • BuiltStorage, services and compute split across separate machines, joined over Tailscale and SMB/CIFS, with a PS2-inspired web interface on GitHub Pages.

Design decision · Dosimeter telemetry

Moving the metrics source onto the machine it measures

Dosimeter's health used to be reported by a separate process on another machine, so the dashboard's view of it depended on that machine staying up. I replaced it with a local Linux metrics service on Dosimeter itself. NILAVUS reads it directly over Tailscale and falls back to Supabase heartbeats when the direct path is down.

  1. Dosimeterlocal Linux metrics service
  2. Tailscaleprivate network path
  3. NILAVUSreads live; Supabase as fallback
